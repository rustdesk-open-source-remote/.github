## Fast Remote Desktop Brief

What is RustDesk? An open-source remote desktop alternative written in Rust.  
Can I self-host it? Yes, you can run your own relay and rendezvous servers.  
Is it free? Completely free with source available under a permissive license.  
Does it need configuration? It works out of the box or with your own server ID.  

## Remote Desktop Overview

RustDesk stands out because its entire codebase is open, letting security-conscious teams audit exactly how connections are established and data flows. Written in Rust, it benefits from memory safety and predictable performance across desktops and mobile devices.

The project's headline feature is self-hosting. Instead of trusting a third-party cloud, you can deploy the lightweight relay server on your own infrastructure, keeping traffic within networks you control and satisfying strict compliance requirements.

For casual users, RustDesk still offers a zero-config public server so a first connection takes seconds. This dual nature—easy for individuals, powerful for enterprises—has driven rapid adoption among people seeking an independent remote access solution.

## Getting Started Playbook

Grab the client using the badge above and open it to reveal your unique ID and one-time password. Share those credentials with whoever needs to connect, or type a peer's ID to initiate a session yourself within moments.

To go private, deploy the hbbs and hbbr server components on a small VPS, then enter that server address in each client's network settings. From that point on every connection routes through your own hardware, giving you complete control over availability and logging.
